# 回帰防止チェックリスト

## 🎯 目的
このリストは、機能変更時に既存機能が壊れないようにするためのチェックリストです。

## 📋 機能別回帰チェック項目

### 🎯 フォーカス・カーソル関連（今回の回帰例）
- [ ] 問題画面表示時に自動で最初のテキストボックスにフォーカスが当たる
- [ ] 正解入力後に次の空欄にフォーカスが移動する
- [ ] キーボードナビゲーション（←→）でフォーカスが移動する
- [ ] 物理キーボード入力後のカーソル位置が正しく保持される
- [ ] カスタムキーボードでの入力がカーソル位置に挿入される
- [ ] 物理キーボード→カスタムキーボードの入力順序でも位置が正しい

### 📝 入力関連
- [ ] テキスト入力が正常に動作する
- [ ] 物理キーボードでの入力が動作する
- [ ] カスタムキーボードでの入力が動作する
- [ ] 削除ボタンが正常に動作する
- [ ] 次問題遷移後もカスタムキーボードが正常に動作する
- [ ] 問題セット選択後もカスタムキーボードが正常に動作する

### 🎮 画面遷移関連
- [ ] 問題セット選択画面が表示される
- [ ] 問題セット選択から学習画面への遷移
- [ ] 全問正解時の自動遷移
- [ ] 「答えを見る」ボタンでの遷移
- [ ] 完了画面から問題セット選択への遷移

### ✅ 回答判定関連
- [ ] 正解判定が正確に動作する
- [ ] 正解時に元のanswerの大文字小文字が正しく表示される
- [ ] 不正解時の処理
- [ ] 複数空欄問題での判定
- [ ] 答え表示画面のAppBarが通常色（緑色でない）で表示される

### 🎉 完了処理関連
- [ ] 全問正解時の完了画面表示
- [ ] 「もう一度挑戦」ボタンの動作
- [ ] 問題のリセット機能

## 🔍 技術的チェック項目

### 状態管理
- [ ] AppStateManagerの状態が正しく更新される
- [ ] 状態変更時の副作用が正常に実行される
- [ ] メモリリークがない（Controller/FocusNodeの破棄）

### パフォーマンス
- [ ] 画面遷移が滑らか
- [ ] 入力応答性が良好
- [ ] メモリ使用量が適正

## 🧪 テスト実行コマンド

### 基本テスト
```bash
# 基本的な回帰テスト
flutter test

# 統合テスト実行
flutter test test/integration/

# 全回帰テスト実行
./scripts/regression_test.sh
```

### 手動テスト手順
1. アプリ起動
2. 問題セット選択
3. 各機能を順番にテスト
4. エラー/異常があればすぐに報告

## 🚨 回帰発生時の対応

### immediate Actions
1. **ロールバック**: `git revert <commit-hash>`
2. **影響範囲の特定**: どの機能が影響を受けたか調査
3. **修正**: 根本原因を特定して修正
4. **再テスト**: 全回帰テストを再実行

### 再発防止
1. **テストケースの追加**: 今回の回帰をカバーするテストを追加
2. **チェックリストの更新**: このリストに新項目を追加
3. **レビュープロセスの改善**: コードレビューでのチェック強化

## 📈 品質メトリクス

定期的に監視する項目：
- テストカバレッジ率
- 回帰の発生頻度
- 修正にかかる時間
- ユーザー報告のバグ数

## 🔄 継続的改善

毎回の修正後に：
1. このリストが有効だったかを評価
2. 漏れた項目があれば追加
3. 不要になった項目は削除
4. チーム全体で知見を共有

**重要**: このリストは生きた文書です。新機能追加や修正のたびに更新してください！
